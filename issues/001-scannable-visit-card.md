# Feature: scannable visit card (QR code)

**What the app does now.** The office visit card carries a unique plan reference
code under the date of the plan. The farmer prints the card and takes it to the
office; the officer can re-open the saved plan by typing that code on the
farmer's device.

**What is rough.** The farmer must read the code out and the officer must type
it. A typo or a misread character means a failed lookup, and a farmer with poor
eyesight may struggle to read the digits aloud.

**What a future version could do.** Add a QR code (or short scannable link) on
the visit card that opens the plan directly from a saved plan, so the officer
never has to type anything.

**Status.** Not built in this round; the reference code is documented as a
no-link nametag that names the plan.
